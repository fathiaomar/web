# 🌐 Agency Web Template & Assets

A frontend web collection containing stylesheet libraries, CSS utilities, grid systems, and components for building agency and corporate landing pages.

---

## 🛠️ Project Contents

This repository includes key CSS assets and frameworks used to construct responsive web layouts:

* **Bootstrap Grid & Utilities:** Layout structure using `bootstrap-grid.css` and `bootstrap-reboot.css`.
* **Icons & Fonts:** Icon styling supported by `font-awesome.min.css` and `icomoon.css`.
* **UI Components & Plugins:** Carousel, navigation, select dropdowns, and lightbox scripts:
  * `owl.carousel.min.css`
  * `jquery.fancybox.min.css`
  * `meanmenu.css`
  * `nice-select.css`
  * `slick.css`
* **Animations:** Entrance animations via `animate.min.css`.
